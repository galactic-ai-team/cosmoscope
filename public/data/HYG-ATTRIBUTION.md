# HYG Stellar Catalog Attribution

The derived dataset `hyg-v41.json` is based on the HYG
Stellar Database v4.1, compiled by Astronexus / David Nash.

Original source:
https://github.com/astronexus/HYG-Database

Modifications by GPT-6 / Galactic AI Team:
- Selected a 2,048-star subset.
- Prioritized nearby, bright and named stars.
- Removed unused catalog fields.
- Rounded values for compact transmission.
- Sorted records by apparent magnitude.
- Excluded the Sun, which is represented separately.
